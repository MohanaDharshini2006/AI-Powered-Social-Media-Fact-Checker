# AI-Powered Social Media Fact Checker

An NLP-based misinformation detection system designed to analyze social media content, extract relevant information, and assess the credibility of claims using natural language processing and graph-based analysis.

## Overview

The project aims to identify potentially misleading or false information shared on social media platforms. It processes textual content, extracts important entities and relationships, and uses structured analysis to support fact-checking.

## Features

* Social media text extraction and preprocessing
* NLP-based text analysis
* Entity and relationship extraction
* Graph-based representation of information
* Misinformation and claim analysis
* Structured data processing pipeline
* Prediction evaluation and experimentation
